# Scene Optimization Analyzer (Unity Editor Plugin)

## Опис
Плагін для редактора Unity, який допомагає швидко знаходити проблеми з оптимізацією на відкритій сцені. Інструмент аналізує кількість об'єктів, складність геометрії (трикутники, вершини), роздільну здатність текстур, освітлення, фізику, UI та глибину ієрархії, після чого формує загальну оцінку (від 0 до 100) та список рекомендацій.

## Встановлення
1. Завантажте папку `Editor` (разом зі скриптом `SceneOptimizationAnalyzer.cs`).
2. Скопіюйте цю папку у ваш проєкт Unity за шляхом: `Assets/Editor/`.
   *(Важливо: скрипт має знаходитися саме в папці Editor, щоб не потрапити у фінальний білд гри).*
3. Дочекайтеся компіляції скриптів в Unity.

## Використання
1. Відкрийте сцену, яку необхідно перевірити.
2. На верхній панелі Unity виберіть пункт меню: **Tools → Scene Optimization Analyzer**.
3. У вікні, що з'явиться, натисніть велику кнопку **ANALYZE SCENE**.
4. Ознайомтеся з детальною статистикою по розділах (Scene, Geometry, Textures, Lighting тощо), а також зверніть увагу на блоки **Problems & Warnings** та **Recommendations**.
5. Щоб зберегти звіт, натисніть кнопку **EXPORT REPORT** — результати будуть збережені у форматі `.txt`.

## Відомі обмеження
* Плагін проводить статичний аналіз сцени і не замінює повноцінний Unity Profiler (не відстежує FPS у реальному часі).
* Аналізатор використовує базові евристики Unity і може не враховувати специфічну оптимізацію сторонніх пакетів з Asset Store.

## Підтримка
* Розроблено для Unity 2022.3 LTS, 2023 LTS та Unity 6.
